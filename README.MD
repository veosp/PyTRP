# Сервис поиска рецептов по ингредиентам

## Назначение

Приложение помогает подобрать рецепты, которые можно приготовить из имеющихся у пользователя ингредиентов.

## Целевая аудитория

Люди, которые готовят дома и хотят быстро найти подходящее блюдо, не покупая дополнительные продукты.

## Предметная область

Сервис хранит рецепты, их категории и необходимые ингредиенты. Пользователь указывает доступные продукты, получает список подходящих рецептов и может добавлять понравившиеся варианты в избранное.

## Основные сущности

- **Рецепт** — название блюда, категория, список ингредиентов и инструкция по приготовлению.
- **Ингредиент** — продукт, который используется в рецепте.
- **Пользователь** — посетитель сервиса со списком избранных рецептов.
- **Категория** — группа рецептов, например «Завтраки» или «Супы».

## Основные функции

- поиск рецептов по доступным ингредиентам; 
- вывод найденных рецептов;
- группировка рецептов по категориям;
- добавление рецепта в избранное пользователя.

## Запуск примера

```bash
python main.py
```
